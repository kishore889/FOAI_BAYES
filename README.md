📘 Bayesian Coin Bias Estimator — Streamlit App

This project demonstrates Bayes’ Theorem using an interactive Bayesian model that estimates the bias of a coin based on observed flip data.
It uses Beta-Binomial conjugacy, making it a perfect educational project for probability, statistics, and machine learning.

🎯 Project Overview

This Streamlit application allows users to:

Select a prior distribution (Uniform, Beta(2,2), Beta(5,5))

Enter the number of coin flips (n)

Enter the number of heads observed (k)

Visualize the prior and posterior distributions

Compute:

Posterior Mean

MAP Estimate (Maximum A Posteriori)

This provides an intuitive and visual explanation of how Bayes’ Theorem updates beliefs with new evidence.
